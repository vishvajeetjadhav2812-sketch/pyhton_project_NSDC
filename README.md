# pyhton_project_NSDC

🍽️ Spice Delight - Restaurant Management Web Application

Spice Delight is a web application built using Python (Flask), HTML5, CSS3, and JavaScript. It provides an intuitive platform for customers to browse the menu, place orders with real-time bill generation, book tables, and submit feedback.

✨ Features

📜 Interactive Menu & Ordering: Browse dishes categorized into Starters, Main Course, and Desserts. Select quantities and get an instant digital bill.

🪑 Table Reservation: Easily book a table by submitting date, time, and guest count.

💬 Customer Feedback: Integrated feedback form for reviews and suggestions.

📱 Responsive Design: Works smoothly across desktops, tablets, and mobile devices.

🚀 Quick Start Guide

Prerequisites

Make sure you have Python 3.x installed on your system.

Installation & Setup

Clone the repository:

git clone https://github.com/vishvajeetjadhav2812-sketch/spice-delight.git
cd spice-delight


Create a virtual environment (Optional but Recommended):

python -m venv venv
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate


Install dependencies:

pip install -r requirements.txt


Run the Application:

python app.py


Open in Browser:
Visit http://127.0.0.1:5000/ in your web browser.
